# Demo

Order fulfillment architecture and independent event contracts.

This catalog documents independent API contracts and real CF-IDP Components.
Native Services represent Components; their declared message selections determine
publishing and consuming relationships. Contracts exist independently of Services.

## Architecture decisions

Contracts remain authoritative in their own Git repositories. Domain and System
relationships come from the existing Domain activation and System API references.

Add business concepts, cross-system processes, and architecture decisions here or
as additional native EventCatalog documentation pages. Generated resources are
build outputs and do not replace these authored pages.

## Fulfillment flow

Reserve inventory before arranging shipment. Order acceptance, stock reservation,
and shipment dispatch are separate business facts documented by independent
contracts. This architecture describes the intended process; it does not claim
that producers or consumers have been deployed.

## Agent discovery

The web UI and native MCP endpoint at `/docs/mcp` expose the same generated
architecture and authoritative contract snapshots. Agents can inspect schemas
and declared relationships without publishing contracts to a second destination.
